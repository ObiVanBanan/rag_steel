# Текущее состояние `rag_steel`

Дата фиксации: 2026-08-04

## Что уже есть

- В корне репозитория находятся `main.py`, `indexer.py`, `config.py`, `search_engine.py`, `mapping_results.csv`, `plan.md` и `tz.md`.
- `main.py` объявляет FastAPI-приложение и пытается использовать `SearchEngine` и `parse_query`.
- `indexer.py` содержит текущую логику индексации CSV в Qdrant.
- `search_engine.py` сейчас пустой.

## Зафиксированные проблемы

- В текущей среде `uv run python -c "import main"` падает на `ModuleNotFoundError: No module named 'fastapi'`.
- Даже если зависимость `fastapi` будет доступна, `main.py` всё равно импортирует `SearchEngine` и `parse_query` из пустого `search_engine.py`, поэтому импорт приложения сейчас не может завершиться корректно.
- Текущая структура проекта не соответствует целевой структуре из `plan.md`.
- В корне нет `pyproject.toml`, `docker-compose.yml`, `README.md`, `tests/`, `src/` и `eval/`, которые перечислены в плане как целевые артефакты.

## Что этот этап должен зафиксировать

- Текущее приложение не готово к поиску в его нынешнем виде.
- Следующие фазы должны начинаться с замены текущих точек входа на новую структуру, а не с точечных правок поверх старого API.
